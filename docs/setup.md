# VibeMaster setup

## 1. Generate the Android host project

The repository contains the Dart application but the native Android host is generated by Flutter. From GitHub Actions, open **Actions → Bootstrap Android → Run workflow**. This workflow runs `flutter create --platforms=android` and commits the generated `android/` directory.

You can also do it locally from the repository root:

```bash
flutter create --platforms=android --org=com.kabibuchuu --project-name=vibemaster .
```

## 2. Connect Firebase

The Firebase project is `vibemaster-75200`.

Install FlutterFire CLI if needed:

```bash
dart pub global activate flutterfire_cli
```

Then from the repository root:

```bash
flutterfire configure --project=vibemaster-75200
```

Select Android. The CLI creates the Firebase app configuration and `lib/firebase_options.dart`.

## 3. Enable Firebase services

In the Firebase console for VibeMaster:

- Authentication → Sign-in method → enable **Anonymous**.
- Firestore Database → create the database.
- Deploy `firestore.rules` after reviewing them.

The application uses anonymous Firebase Auth for the MVP so users can enter a room without creating an account.

## 4. Run

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## 5. YouTube

VibeMaster embeds YouTube through the official IFrame player. It does not download, extract, proxy, or cache YouTube audio.
